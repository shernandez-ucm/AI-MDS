% SSD300 (Liu et al., 2016): VGG-16 truncado (13 conv, sin FC) + capas adicionales
% multi-escala. Cada feature map fuente pasa por una conv 3x3 que predice, por
% anchor, (x, y, w, h) + 20 clases:
%   conv4_3   38x38x512    4 anchors -> 38x38x96
%   conv7     19x19x1024   6 anchors -> 19x19x144
%   conv8_2   10x10x512    6 anchors -> 10x10x144
%   conv9_2    5x5x256     6 anchors ->  5x5x144
%   conv10_2   3x3x256     4 anchors ->  3x3x96
%   conv11_2   1x1x256     4 anchors ->  1x1x96
% Total: 38^2*4 + 19^2*6 + 10^2*6 + 5^2*6 + 3^2*4 + 1*4 = 8732 cajas.
