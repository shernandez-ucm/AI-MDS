% DETR (Carion et al., 2020, arXiv:2005.12872), Fig. 2 y Fig. 10:
%   backbone ResNet-50/101: 3 x 800 x 1066 -> 2048 x 25 x 34 (stride 32)
%   conv 1x1: 2048 -> d = 256, aplanar a d x HW (HW = 25*34 = 850 tokens)
%   + codificaci\'on posicional sinusoidal
%   encoder: 6 capas (self-attention 8 heads, FFN 2048, dropout 0.1)
%   decoder: 6 capas, N = 100 object queries aprendidas (self + cross-attention),
%            decodificaci\'on en paralelo
%   heads compartidos entre queries: clase (C + 1, "sin objeto") y caja (x, y, w, h)
%   entrenamiento: emparejamiento bipartito (algoritmo h\'ungaro), sin NMS ni anchors
