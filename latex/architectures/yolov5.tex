% YOLOv5 (Ultralytics, 2020), seg\'un Terven et al., "A Comprehensive Review of
% YOLO Architectures in Computer Vision" (arXiv:2304.00501), Fig. 13 (YOLOv5l):
% backbone CSPDarknet53 modificado (Stem + 4 etapas Conv/2 + C3, SPPF),
% neck CSP-PAN (FPN top-down + PAN bottom-up), head tipo YOLOv3 en 3 escalas.
% Todas las convoluciones: Conv + BN + SiLU. Entrada 640x640.
%   Stem      Conv 6x6/2, 64                     -> 320
%   etapa 2   Conv 3x3/2, 128  + C3 x3           -> 160
%   etapa 3   Conv 3x3/2, 256  + C3 x6           ->  80   (P3, H/8)
%   etapa 4   Conv 3x3/2, 512  + C3 x9           ->  40   (P4, H/16)
%   etapa 5   Conv 3x3/2, 1024 + C3 x3 + SPPF    ->  20   (P5, H/32)
%   neck      Conv 1x1 512 -> up -> concat P4 -> C3 512 -> Conv 1x1 256 -> up
%             -> concat P3 -> C3 256 (salida P3)
%             -> Conv 3x3/2 -> concat -> C3 512 (salida P4)
%             -> Conv 3x3/2 -> concat -> C3 1024 (salida P5)
%   head      Conv 1x1 por escala: 3 anchors x (x, y, w, h, conf + 80 clases) = 255
