\begin{frame}{De Modelos Lineales a No Lineales}
  \begin{block}{Limitaciones de los Modelos Lineales}
    Los modelos lineales, como la regresión logística o la regresión lineal, son potentes pero tienen una limitación fundamental: solo pueden aprender relaciones lineales entre las características de entrada y la salida.
  \end{block}
  
  \begin{alertblock}{El problema XOR}
    Un ejemplo clásico es el problema de la compuerta XOR. No es posible trazar una única línea recta para separar las clases.

\section{Funciones de Activación}
%------------------------------------------------

\begin{frame}{Funciones de Activación}
  Si solo apiláramos transformaciones lineales (afines), la red completa seguiría siendo un modelo lineal.
  
  \begin{block}{No Linealidad}
    Para aprovechar el potencial de las arquitecturas multicapa, necesitamos incorporar una \textbf{función de activación no lineal} ($\sigma$) que se aplica a la salida de cada neurona en las capas ocultas. 
  \end{block}
  
  \begin{itemize}
    \item La salida de una neurona en la capa oculta incorpora una función de activación no-lineal. 
    \begin{align*}
    \begin{split}\begin{aligned}
    \mathbf{h} & =\sigma(  \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)}), \\
    \mathbf{o} & =\sigma( \mathbf{W}^{(2)}\mathbf{h} + \mathbf{b}^{(2)}).
\end{aligned}\end{split}
    \end{align*}
    
    \item Introduce no linealidades que permiten a la red aprender relaciones complejas como la de la compuerta XOR.
  \end{itemize}
\end{frame}

\begin{frame}{Backpropagation}
  \begin{block}{Retropopagación del error}
    El objetivo del entrenamiento es encontrar los valores de los parámetros $\theta=\{\mathbf{W}^i,\mathbf{b}^i\}\vert_{i=1}^d$  que minimicen una \textbf{función de pérdida}  $\mathcal L( y,\hat y).$.
  \end{block}
 
   \begin{enumerate}
    \item \textbf{Propagación hacia adelante (Forward Pass):} Se introduce un lote de datos en la red y se calcula la salida y el error (pérdida).
    \item \textbf{Propagación hacia atrás (Backward Pass):} Se calcula el gradiente de la función de pérdida con respecto a cada parámetro (pesos $\mathbf{W}^i$ y sesgos $\mathbf{b}^i$) de la red, comenzando desde la capa de salida y avanzando hacia atrás.
    \item \textbf{Actualización de parámetros:} 
      \[ \theta \leftarrow \theta - \eta \nabla_\theta \mathcal L \]
  \end{enumerate}

\end{frame}

\section{Regularización y Problemas Comunes}
%------------------------------------------------

\begin{frame}{Sobreajuste (Overfitting)}  
  \begin{block}{Sobreajuste}
  Las redes neuronales, al tener una gran capacidad (muchos parámetros), corren el riesgo de \textbf{sobreajuste}.  Ocurre cuando el modelo aprende "demasiado bien" los datos de entrenamiento, incluyendo el ruido, y pierde la capacidad de generalizar a datos nuevos no vistos. 
  \end{block}
  \begin{columns}
    \begin{column}{0.5\textwidth}
      El sobreajuste ocurre cuando una red se apoya excesivamente en un conjunto pequeño de neuronas o características para hacer sus predicciones. Esto la hace vulnerable a pequeñas variaciones en los datos de entrada.
    \end{column}
    \begin{column}{0.5\textwidth}
      \begin{figure}
        \includegraphics[width=\textwidth]{figures/capacity-vs-error} % Reemplazar con un gráfico de error de entrenamiento vs. validación
      %  \caption{El error de entrenamiento disminuye, pero el de validación aumenta.}
      \end{figure}
    \end{column}
  \end{columns}
\end{frame}

\begin{frame}{Técnica de Regularización: Dropout}
  \textbf{Dropout} es una técnica de regularización simple y efectiva introducida para combatir el sobreajuste. 
  
  \begin{block}{Dropout}
    Durante el entrenamiento, en cada paso, se "apagan" (ponen a cero) aleatoriamente un subconjunto de neuronas. Esto obliga a la red a no depender de ninguna neurona individual y a aprender características más redundantes y robustas. 
  \end{block}

\begin{frame}[shrink]{Dropout en la Práctica}
  \begin{block}{Mecanismo}
    Para una capa oculta $\mathbf{h}$, aplicamos dropout de la siguiente manera:
    \begin{enumerate}
      \item Se define una \textbf{probabilidad de abandono} $p$ (e.g., $p=0.5$). 
      \item Durante el entrenamiento, cada neurona $h_i$ se pone a cero con probabilidad $p$.
      \item Las activaciones de las neuronas restantes se escalan por un factor de $1/(1-p)$.
    \end{enumerate}
    \[ h'_i = \begin{cases} 0 & \text{con probabilidad } p \\ \frac{h_i}{1-p} & \text{con probabilidad } 1-p \end{cases} \]
  \end{block}
  \pause
  \begin{alertblock}{¿Por qué escalar por $1/(1-p)$?}
    Esta técnica se llama \textbf{Abandono Invertido (Inverted Dropout)}. El escalado asegura que el valor esperado de la salida de la capa se mantenga igual durante el entrenamiento y la prueba.
    \[ E[h'_i] = p \cdot 0 + (1-p) \cdot \frac{h_i}{1-p} = h_i \]
  \end{alertblock}
\end{frame}

\begin{frame}{Entrenamiento vs. Inferencia}
  El comportamiento de una capa con Dropout es fundamentalmente diferente en cada fase.
  
  \begin{block}{Durante el Entrenamiento (Training)}
    \begin{itemize}
      \item Dropout está \textbf{activo}.
      \item En cada iteración de propagación hacia adelante, se genera una máscara de abandono diferente y se aplica a las neuronas.
      \item Esto introduce ruido y regulariza el modelo, forzándolo a generalizar. 
    \end{itemize}
  \end{block}
  \pause
  \begin{block}{Durante la Inferencia (Test/Predicción)}
    \begin{itemize}
      \item Dropout está \textbf{desactivado}. 
      \item Se utiliza toda la red (todas las neuronas están activas) para hacer la predicción.
      \item Esto equivale a promediar las predicciones de la exponencial cantidad de sub-redes generadas durante el entrenamiento. 
    \end{itemize}
  \end{block}
\end{frame}

\begin{frame}{Estabilidad Numérica}
  Entrenar redes profundas puede ser difícil debido a problemas de estabilidad numérica.
  \begin{align}
  \partial_{\mathbf{W}^{(l)}} \mathbf{o} = \underbrace{\partial_{\mathbf{h}^{(L-1)}} \mathbf{h}^{(L)}}_{ \mathbf{M}^{(L)} \stackrel{\textrm{def}}{=}} \cdots \underbrace{\partial_{\mathbf{h}^{(l)}} \mathbf{h}^{(l+1)}}_{ \mathbf{M}^{(l+1)} \stackrel{\textrm{def}}{=}} \underbrace{\partial_{\mathbf{W}^{(l)}} \mathbf{h}^{(l)}}_{ \mathbf{v}^{(l)} \stackrel{\textrm{def}}{=}}.
  \end{align}
  
  \begin{alertblock}{Desvanecimiento de Gradientes (Vanishing Gradients)}
    A medida que los gradientes se propagan hacia atrás, pueden volverse extremadamente pequeños, haciendo que las primeras capas de la red aprendan muy lentamente o dejen de aprender. Es común con funciones como la sigmoide.
  \end{alertblock}
  
  \begin{alertblock}{Explosión de Gradientes (Exploding Gradients)}
    Lo contrario: los gradientes se vuelven enormes, provocando actualizaciones muy grandes en los pesos y haciendo que el entrenamiento sea inestable.
  \end{alertblock}

\section{Resumen}
%------------------------------------------------

\begin{frame}{Resumen y Conclusiones}
  \begin{itemize}
    \item El Perceptrón Multicapa (MLP) supera las limitaciones de los modelos lineales al introducir \textbf{capas ocultas} y \textbf{funciones de activación no lineales}.
    \item El entrenamiento se realiza mediante el algoritmo de \textbf{retropropagación}, ajustando los pesos para minimizar una función de pérdida.
    \item El \textbf{sobreajuste} es un riesgo importante, y se combate con técnicas de regularización como \textbf{Dropout}. 
    \item La \textbf{estabilidad numérica} (desvanecimiento/explosión de gradientes) es un desafío clave en el entrenamiento, abordado con una correcta inicialización de parámetros y arquitecturas adecuadas.
  \end{itemize}
\end{frame}
